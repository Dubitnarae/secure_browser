# YD Browser

화면 캡처를 막고 보안 로그를 남기는 Windows용 간단한 웹 브라우저입니다. (PyQt6 + QtWebEngine)

## 설치와 실행
1. [Releases](https://github.com/Dubitnarae/secure_browser/releases)에서 `YD_Browser_v<버전>.zip`을 내려받습니다.
2. 압축을 풉니다. (폴더 전체가 한 세트이므로 `YD_Browser.exe`만 따로 옮기면 안 됩니다)
3. `YD_Browser.exe`를 실행합니다.

방문 기록·북마크·설정·로그는 `YD_Browser.exe`와 같은 폴더에 저장됩니다.

## 주요 기능
- **화면 캡처 방지**: 창이 캡처·화면 공유에서 제외됩니다. (Windows 10 2004 이상. 그보다 낮은 버전에서는 캡처 화면이 검게 나옵니다)
- **PrintScreen 감지**: 감지하면 보안 로그에 기록하고 클립보드를 비웁니다.
- **녹화·원격 프로그램 감지**: OBS, Bandicam, ShareX, AnyDesk, TeamViewer, 원격 데스크톱 세션 등이 실행 중이면 경고하거나 화면을 가립니다. (설정에서 선택)
- **저장 데이터 암호화**: 방문 기록·북마크는 Windows 계정 암호화(DPAPI)로 저장됩니다.
- **다운로드 차단, 카메라·마이크·위치 권한 자동 거부**
- **보안 로그**: 화면 오른쪽 로그 창과 `security.log` 파일에 기록됩니다. 1MB가 넘으면 새 파일로 교체하고 지난 파일 3개를 보관합니다.
- **스마트 주소창**: 주소면 이동하고, 아니면 선택한 검색 엔진(구글·네이버·빙·덕덕고)으로 검색합니다.
- 탭, 북마크, 방문 기록, 페이지 내 찾기, 확대·축소, 창 크기·마지막 탭 기억
- 하루 한 번 새 버전 확인 (설정에서 끌 수 있음)

## 단축키
| 키 | 동작 |
|---|---|
| Ctrl+T / Ctrl+W | 새 탭 / 탭 닫기 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl+L, F6 | 주소창으로 이동 |
| F5 | 새로고침 |
| Alt+← / Alt+→ | 뒤로 / 앞으로 |
| Ctrl+F | 페이지에서 찾기 (Esc로 닫기) |
| Ctrl+= / Ctrl+- / Ctrl+0 | 확대 / 축소 / 원래 크기 |

## 설정 (⚙ 설정 버튼)
시작 페이지, 검색 엔진, 시작할 때(시작 페이지 / 마지막 탭 복원), 방문 기록 저장 여부, 다운로드 허용, 녹화·원격 프로그램 감지 방식(확인 안 함 / 경고만 / 화면 가리기), 업데이트 확인.

## 알아둘 점
- 암호화된 저장 파일은 **만든 Windows 계정에서만** 열 수 있습니다. 다른 PC나 다른 계정으로 옮기면 읽을 수 없고, 읽지 못한 파일은 `.broken_날짜` 이름으로 보관한 뒤 새로 시작합니다.
- 보안 로그(`security.log`)와 `settings.json`은 암호화하지 않습니다.
- 캡처 방지는 일반적인 캡처·화면 공유·녹화를 막지만, 스마트폰 카메라로 화면을 찍는 것은 막을 수 없습니다.
- Win+Shift+S 같은 Windows 기본 캡처 단축키는 감지하지 못합니다. (캡처 방지로 화면은 보호됩니다)
- 새 버전 확인은 GitHub에 접속합니다. 접속을 원하지 않으면 설정에서 끄세요.

## 소스에서 실행하고 빌드하기
```
pip install PyQt6 PyQt6-WebEngine pyinstaller
python "secure_browser v1.6.py"
.\build.ps1
```
`build.ps1`은 `dist\YD_Browser_v<버전>.zip`과 SHA256 파일을 만듭니다.
